# 高考专业方向决策辅助工具

> 面向考生与家长的**专业方向决策辅助工具**。首版只做**方向组级**分析，不做具体专业级、院校级、录取概率级结论。

## 简介

适合"已经有 2 到 5 个模糊候选方向，但不会权衡"的用户。通过 8–12 分钟的问卷，输出 3–5 个值得重点研究的方向组、市场现实校验与方向对比报告。

## 本地启动

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 即可使用。

## 测试

```bash
npm test
```

## 类型检查

```bash
npm run typecheck
```

## 技术栈

- Next.js 15（App Router）
- React 18
- TypeScript
- Tailwind CSS
- Zod（输入校验）
- Vitest + Testing Library（测试）

## 目录结构

```
app/                    # Next.js 路由与页面
  page.tsx              # 首页
  questionnaire/        # 问卷页
  report/               # 报告页
components/             # 展示与表单组件
  questionnaire/        # 问卷相关
  report/               # 报告相关
data/                   # 静态数据（方向组、问卷选项）
lib/
  validation/           # Zod schema
  scoring/              # 规则引擎与报告生成
  session/              # 浏览器 sessionStorage 抽象
types/                  # TypeScript 类型
tests/                  # 单元与集成测试
```

## 首版边界

- ✅ 只做**方向组级**决策辅助（10 个方向组）
- ✅ 主观偏好 + 客观市场现实双引擎
- ✅ 轻中度问卷（10–13 题，8–12 分钟）
- ❌ **不**做志愿填报完整方案
- ❌ **不**做院校录取概率预测
- ❌ **不**做"最适合专业"式黑箱推荐
- ❌ **不**接第三方 API / 实时数据

## 合规边界

本工具：
- 用于专业方向决策**辅助**，不替代官方招生政策、院校章程与录取规则
- 不承诺录取结果、就业结果、薪资结果
- 不构成唯一正确答案

文案中**禁用**："最适合" "最优解" "精准匹配" "保证不后悔" "一定更好就业" "一定更有前途"。

## 10 个方向组

1. 计算机、数据与人工智能类
2. 工程、自动化与智能制造类
3. 医学与健康服务类
4. 财经管理类
5. 法学与公共事务类
6. 教育与师范类
7. 传媒、内容与传播类
8. 设计与艺术应用类
9. 基础学科与科研潜力类
10. 语言、人文与社会科学类
